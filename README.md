Final Project – CS 324E
Developed in MonoGame

Overview

This project is a fully playable recreation of Pac-Man built using C# and MonoGame.
It includes:
- A tile-based maze rendered from an image
- A MazeMap system to interpret walls and paths
- A DotManager that generates dots and power pellets based on the maze layout
- Player-controlled Pac-Man with smooth movement, animation, and sound
- Four ghosts (Blinky, Pinky, Inky, Clyde) with classic scatter behavior
- Score tracking and high-score saving
- A start screen and game-over screen
- Optional sound mute/unmute button

How to Play

Running the Game:
- Ensure you have the MonoGame 3.8+ SDK installed.
- Open the project in Visual Studio.
- Build all the assets in MGCB
- Click Run or press F5 to start the game.
Movement: 
- Use the arrow keys (UP, DOWN, LEFT, RIGHT) to control Pac-Man
- Pac-Man will begin moving in a direction as soon as it becomes valid
Sound Controls:
- Press M to mute/unmute music
- Press K to mute/unmute sound effects
- Mouse click on the sound icon (top-right corner) during gameplay to mute/unmute
- Music and sounds found at https://www.classicgaming.cc/classics/pac-man/sounds#google_vignette 
High Score:
- Highest score in all history will be saved as high score
- Current score is shown on the Game Over screen
